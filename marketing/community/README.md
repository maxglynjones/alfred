# Community announcement structure

Introduce Alfred as a self-hosted iOS-focused assistant for Even G2, backed by Home Assistant. Show a short genuine demo. Describe quick home/list commands, reminders, optional mail/calendar/research providers and the minimal display.

Link the published repository quick start, controls and current limitations. Explain that each installed Even package must allow the user's exact backend origin; the owner package is not a universal download. Invite concrete reproduction steps and device/firmware versions in issue reports, without transcripts or credentials. Identify experimental paths clearly.

Public reference material: [features](../../docs/FEATURES.md), [engineering choices](../../docs/development/ENGINEERING.md), [technical evidence](../../docs/development/TECHNICAL-REFERENCE.md), [privacy boundaries](../../docs/setup/PRIVACY.md) and [editable architecture visuals](diagrams/README.md). Owner announcement drafts and publication notes stay outside this repository. A source launch and a universal Even Store release are separate milestones.

Original [introduction and connection illustrations](illustrations/README.md) accompany the genuine [UI captures](screenshots/README.md). Keep illustration / browser-preview / configured-reference captions explicit.
